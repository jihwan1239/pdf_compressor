# PDF 용량 줄이기

원하는 최대 용량을 정하면 그 이하가 될 때까지 PDF를 단계적으로 압축해 주는 윈도우용 프로그램입니다.
설치 없이 exe 파일 하나로 실행됩니다.

## 주요 기능

- 목표 용량 지정 (MB 또는 KB)
- 여러 파일 한 번에 처리
- 압축 단계(1, 2, 3)를 골라서 사용 가능
- 화질을 최대한 지키는 방향으로, 목표를 만족하는 가장 약한 압축에서 멈춤
- 원본은 건드리지 않고 `파일명_compressed.pdf`로 저장
- 진행 중 취소, 마지막 설정 기억

## 사용법

1. `PDFCompressor.exe`를 실행합니다.
2. `추가`를 눌러 PDF 파일을 고릅니다.
3. 목표 용량을 입력합니다. 예: 5 MB
4. 사용할 압축 단계를 고릅니다. (기본값은 1, 2, 3단계 모두)
5. `압축 시작`을 누릅니다.

## 압축 방식

| 단계 | 내용 | 화질 | 텍스트 선택 |
| --- | --- | --- | --- |
| 1 | 무손실 최적화 | 변화 없음 | 유지 |
| 2 | 내부 이미지의 해상도와 품질을 단계적으로 낮춤 | 이미지만 저하 | 유지 |
| 3 | 페이지 전체를 이미지로 변환 (옵션) | 저하 | 불가 |

선택한 단계만 1, 2, 3 순서로 시도하고, 목표 용량에 도달하면 거기서 멈춥니다.
텍스트를 꼭 유지해야 하면 3단계를 끄세요.
목표에 도달하지 못하면 가장 작게 줄어든 결과를 저장하고 알려 줍니다.

## 제한 사항

- 암호가 걸린 PDF는 처리하지 않습니다.
- 손상된 PDF는 열지 못할 수 있습니다.
- 이미 최적화된 PDF는 목표 용량까지 줄어들지 않을 수 있습니다.

## 개인정보

모든 처리는 사용자의 PC 안에서만 이루어집니다. 파일이나 사용 기록이 외부로 전송되지 않습니다.
마지막 설정(목표 용량, 저장 위치 등)만 `%APPDATA%\PDFCompressor\settings.json`에 저장됩니다.

## 다운로드 확인

받은 exe가 변조되지 않았는지 확인하려면 릴리스에 함께 올라온 `SHA256.txt`의 값과 비교하세요.

```
certutil -hashfile PDFCompressor.exe SHA256
```

서명되지 않은 exe라서 윈도우 SmartScreen 경고가 뜰 수 있습니다.
이 저장소의 소스코드로 직접 빌드한 파일임을 확인할 수 있습니다.

## 직접 빌드하기

PC에서는 `build.bat`을 실행하면 `dist\PDFCompressor.exe`가 만들어집니다. (파이썬 3.10 이상 필요)

GitHub에서는 `Actions` 탭의 `Build Windows exe`를 실행하거나, `v1.0.0` 같은 태그로 릴리스를 만들면
자동으로 exe가 빌드되어 릴리스에 첨부됩니다.
